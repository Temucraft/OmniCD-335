# OmniCD

An addon that provides real-time updates on your teammates' cooldowns and abilities. Improving awareness and coordination, it will ensure that you never miss a crucial moment, empowering you to respond effectively whether you're tackling a boss or engaging in PvP battles. With [**OmniCD**](#), you can elevate your gameplay and foster better teamwork, making every encounter more enjoyable!

#### ⋮ KEY FEATURES

- Track any spell and item cooldown.
- Visual cues when abilities active or used.
- Options to add, remove, disable or change priority/order of each ability.
- Many customizable visual options, such as icon size, alignment, border, spacing and rows.
- Option to automatically anchor to the corresponding unit frames.
- Popular unit frame addon support such as ElvUI, XPerl, Pitbull, Grid, CompactRaidFrame etc.
- Tooltips to read more information about new spells when displayed.
- Extra bars allowing you to organize and track specific cooldowns.
- Sync abilities and glyph information (if your teammate also has OmniCD).
- And much more!

<details>
<summary>Installation Instructions</summary>

1. Extract the downloaded compressed files _(eg. Right-Click -> Extract-All)_.
2. Navigate within each extracted folder(s) looking for the following: `OmniCD` or `!!!ClassicAPI`.
3. Move folder(s) named `OmniCD` or `!!!ClassicAPI` to your client `Interface\AddOns\` folder.
4. Re-launch client.

**Directory Structure:**
<pre>
Client Directory
└── Interface
    └── AddOns
        └── OmniCD
            └── OmniCD.toc
            └── ...
